
# Emotion Detection Web Application

An AI-powered emotion detection application
developed using IBM Watson NLP and Flask.

## Features

- Detects anger, disgust, fear, joy and sadness
- Identifies the dominant emotion
- Provides a Flask web interface
- Handles invalid text input
- Includes automated unit tests
- Supports static code analysis using Pylint

## Technologies

Python, Flask, IBM Watson NLP, Requests, Unittest
